## About Wave

Wave is a native Windows utility for executing Lua scripts during Roblox sessions. It runs as an independent desktop program, keeps its resource footprint small, and provides direct injection for script execution. The setup is intended for people testing or experimenting with custom Lua scripts in Roblox without a complicated installation flow or registration key.

A curated hub is included for accessing more than 500 community-created scripts. Its collection covers automation, gameplay enhancements, and utility features for a range of popular Roblox experiences. Wave checks for new releases when it starts, helping it stay aligned with current Roblox client versions while retaining a clean interface designed for Windows 10 and 11.

## Frequently Asked Questions

**Is Wave safe to use?**  
Wave is supplied as-is for educational and testing use. Each user is responsible for their use of the software and for any resulting consequences.

**Does Wave support the newest Roblox release?**  
Its automatic update system is intended to maintain compatibility with current Roblox versions. When a Roblox update causes a problem, a Wave patch will typically be released within a few days.

**What distinguishes Wave from other script executors?**  
Wave combines a lightweight, no-key-required design with an integrated script hub and a queue that remains available across sessions. Local SQLite storage and batch execution are additional capabilities that simpler alternatives may not provide.

**Could using Wave result in a Roblox account ban?**  
Third-party script execution tools are against Roblox's Terms of Service. Accounts may be suspended or terminated, so use Wave at your own risk and consider using alternate accounts.

**Where does Wave keep my scripts?**  
User scripts and queue information remain on the local machine in the `data/` directory, stored in SQLite format. The software does not transmit this data to external servers.
